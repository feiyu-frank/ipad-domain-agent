## 📋 项目介绍

**ipad-domain-agent** 是一套基于 WeChat Pad 协议打造的高级管理工具，致力于为个人与企业用户提供稳定、高效、开箱即用的微信+企业微信自动化解决方案。

传统微信机器人与企业微信机器人方案普遍存在掉线频繁、风控严格、部署复杂等痛点。本项目通过持续迭代的协议适配与完善的登录状态管理，实现长时间稳定在线；配合丰富的 API 接口，可轻松完成消息收发、好友管理、群管理、朋友圈互动等常见操作，并支持通过 Webhook 将消息实时推送至你的业务系统。

无论是搭建智能客服、社群运营助手，还是数据统计与自动化工作流，都能在几分钟内完成部署并快速接入。

## 📝 功能特性

### 🔐 多种登录方式

- ✅ **二维码登录** —— 获取登录二维码，扫码即用
- ✅ **验证码登录** —— 自动处理验证码提交，无需手动获取 ticket
- ✅ **短信登录** —— 支持短信验证码登录方式
- ✅ **设备登录** —— 支持 A16 数据登录与设备 ID 登录
- ✅ **自动 Token 刷新** —— 过期自动检测并刷新，使用过程无缝切换

### 🤖 自动化增强

- 🔧 **自动化操作** —— 自动抢红包、消息防撤回、自动通过好友请求、多群消息同步
- 👑 **高级群管理** —— 建群、拉人、踢人、邀请成员、群公告发布、修改群名称

### 📡 消息推送与稳定性

- 📤 **Webhook 实时推送** —— 消息实时回调至指定 URL，支持自定义消息类型过滤
- 🔐 **签名验证** —— HMAC-SHA256 消息签名校验，失败自动重试
- 🐇 **RabbitMQ 消息队列** —— 消息持久化不丢失，智能重连、心跳健康监控
- 👥 **多账号管理** —— 多账号并行运行、账号相互隔离、统一接口管理
